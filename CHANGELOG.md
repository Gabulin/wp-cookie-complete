# Изменения

## 1.0.14

- Сохранены CSS-класс `font-nunito` и прежняя цепочка резервных шрифтов для обновления старых установок без изменения оформления.
- Обновлены версии ресурсов для браузерного кеша.

## 1.0.13

- Объединены исходники GitHub и доработки сайта saint в одной версии.
- Добавлена поддержка полного кода счётчиков с `<script>` без вложенных тегов; JavaScript без тегов поддерживается как прежде.
- Сохраняется порядок внешних и встроенных скриптов; `<noscript>` и его пиксель не вставляются.
- Обновлены подписи полей скриптов в настройках и версии ресурсов для обновления кеша браузера.
- Добавлены настройки скругления дорожки и бегунка для трёх размеров экрана.
- Сохраняются CSS-классы ссылок текста плашки, включая TinyMCE.
- Сохранены стандартная палитра и режим из GitHub. Индивидуальные сохранённые настройки сайта имеют приоритет.
- Добавлены браузерные и PHP-проверки, инструкция обновления единым комплектом файлов.
- Правка подписи согласия Contact Form 7 сохранена отдельным примером для темы и не применяется плагином автоматически.
